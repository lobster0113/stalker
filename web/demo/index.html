설정 1-2 · 캐시게임 조건

학습된 TP-GTO는 6인 100BB 캐시에서 학습했어요. 매 핸드 모든 좌석을 100BB로 맞추고(탑업·초과분 적립), 세션 손익은 따로 보여 줘요. 다른 인원·스택은 학습이 끝나면 열립니다.

내 약점

TP 항목별 평균 점수. 낮은 항목은 학습 섹션에서 집중 연습하세요.

기록 옮기기 (다른 기기·브라우저로)

아래 텍스트를 복사해 다른 기기의 '가져오기' 칸에 붙여넣으세요. 파일을 내려받지 않아요.

내 차례가 오면

  1. 보드 읽기 · 누구 레인지에 유리한가, (고수) 넛은 누가 더 많은가 — 헤즈업 플랍 이후
  2. 상대 읽기 · 성향 0–100(기회가 쌓인 뒤), 13×13 레인지, 방금 벳은 밸류 쪽인가
  3. 내 핸드 · 쇼다운 에퀴티, 다음 카드 중 유리·불리해지는 비율
  4. 액션 · 폴드·체크·콜, 벳·레이즈는 최소 레이즈부터 올인까지 원하는 금액 — 학습된 TP-GTO의 혼합 전략과 비교해요(참고용, 점수에 넣지 않음)
  5. 액션 점검 · 고른 액션에 맞는 근거: 레이즈면 그 사이즈에 상대가 접을 확률, (토너먼트) 콜이면 상금 구조까지 생각한 필요 승률

배우는 순서대로 놓았어요. 족보부터 시작해 에퀴티, 레인지, 보드 순으로 올라갑니다. 문제마다 쉬움은 상대 핸드를, 보통은 상대 레인지를, 어려움은 테이블의 액션만 보여주고, 정답에는 왜 그런지를 함께 보여줘요.

복기용 Training Game

실전 핸드를 입력하면, 갈린 판단을 찾아드려요.

포지션 → 핸드 → 프리플랍 → 플랍 → 턴 → 리버 → 쇼다운 순서로, 테이블 위에서 자리마다 액션을 눌러 입력하세요. 마지막 내 결정을 TP-GTO(학습된 정책이 없는 설정은 규칙 기반 모의 교사)의 판단과 비교하고, 비슷한 상황으로 바로 훈련할 수 있어요.
