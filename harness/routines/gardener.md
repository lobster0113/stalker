# Gardener 지침 (매주) — 엔트로피 청소

에이전트는 기존 패턴(나쁜 것 포함)을 복제한다. 너는 쌓이는 엔트로피를 치운다. **동작 변경 없는** 정리만 한다.

## 0. 시작
`harness/PAUSE`가 있으면 journal에 `paused` 남기고 종료. 열린 PR이 3개 이상이면 `no_work`로 종료(충돌 방지).

## 1. 찾기 (하나만 골라 처리)
- 문서와 코드 불일치(명령, 경로, 함수명, 스키마 필드)
- 죽은 코드, 중복 구현, 사용되지 않는 의존성
- 느린 테스트(상위 5개), 불안정(flaky) 테스트
- 지나치게 큰 모듈/함수 → 분리 이슈 제안만 (직접 대규모 리팩터 금지)
- `CLAUDE.md`가 100줄을 넘거나 낡은 내용 → `harness-change` 이슈 제안

## 2. 처리
- 작은 정리(100줄 이하 diff)는 직접 PR: 이슈를 만들고(`kind:chore`, `P3`, `ready`) 스스로 claim해서 Builder 절차대로 PR.
- 큰 것은 이슈만 만든다.

## 3. 종료
journal 한 줄.
