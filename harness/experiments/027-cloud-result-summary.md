# 027: 1MB 넘는 클라우드 결과도 요약을 ops에 게시
- 상태: 진행 중
- 제안: builder-b, 2026-10-29 / 이슈 #358 / PR #369
## 문제 (관측 근거: 실험 024)
결과 JSON이 1MB를 넘으면 ops에는 로그만 남아, 모델 블롭이 큰 파드 결과의 지표를 에이전트가 ops에서 읽을 수 없다.
## 가설
큰 문자열 필드(모델 블롭)를 `{omitted_chars, sha256}`로 바꾼 요약을 `<run_id>.summary.json`으로 게시하면 지표는 보존되고 크기는 1MB 아래로 내려간다.
## 변경
`harness/cloud/launcher.py`의 `publish()`에 1MB 초과 분기(`_strip_blobs`)를 추가. 원본 전체를 `check_result`(비밀 검사)한 뒤 요약도 재검사. 요약도 1MB를 넘으면 기존처럼 로그만.
## 측정 지표와 측정창
머지 후 첫 1MB 초과 파드 결과 3건 또는 7일 중 먼저 오는 쪽. 지표: 1MB 초과 결과 중 ops에 요약이 게시된 비율, 요약 크기.
## 성공 기준 (수치)
1MB 초과 결과의 ops 요약 게시율 100%, 요약 크기 ≤1MB, 비밀 검사 실패 0건.
## 롤백 방법
PR revert — 1MB 초과 결과는 다시 로그만 게시된다.
