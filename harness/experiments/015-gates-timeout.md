# 015: CI gates 잡 시간 상한 30분 → 50분
- 상태: 진행 중
- 제안: 대화 세션, 2026-10-27 / 이슈 #199 / PR (이 PR)
## 문제 (관측 근거)
- 10-27 오후부터 PR CI의 `gates` 잡 대부분이 30분 상한에 걸려 cancelled(#135 #136 #137 #139 #158 #173 #180 #183 #193 #195). reviewer·reviewer-b journal은 `waiting_ci`만 반복했다(14:29Z, 15:10Z).
- #190(pytest-xdist)으로 tests 단계가 1256s → 937s로 줄었다. 그래도 잡 전체는 29분 52초다. gate_r --full 단독이 801s다(#190 코멘트).
## 가설
상한을 50분으로 올리면 검사 범위를 줄이지 않고 타임아웃 취소가 사라진다. 판정 대기는 잡 시간(약 30분)만큼만 걸린다.
## 변경
`.github/workflows/ci.yml` `gates.timeout-minutes` 30 → 50. 다른 잡과 잡 이름은 그대로다(필수 체크 영향 없음).
## 측정 지표와 측정창
머지 후 7일. (1) PR·main CI `gates` 결론 중 cancelled 비율(동시성 취소 제외, timeout만), (2) journal의 `waiting_ci` 건수, (3) `gates` 잡 소요 시간 중앙값.
## 성공 기준
(1) 타임아웃 취소 0건, (2) 머지 전 하루 대비 절반 이하, (3) 40분 이하(넘으면 잡 분할 후속 이슈를 연다).
## 롤백 방법
이 PR을 revert.
