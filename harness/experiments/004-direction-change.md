# 004: 방향 전환(TP-GTO)에 맞춘 역할 지침 개정
- 상태: 진행 중
- 제안: 대화 세션(사용자 지시), 2026-10-27 / ADR 0008
## 문제
사용자가 원문 요구사항을 바꿨다(`docs/ORIGIN.md`). 기존 지침은 ICMizer 상회·유형화 충분성을 향해 큐를 채워, 새 목표(따라 할 수 있는 GTO, 데모 사이트 우선)와 어긋난 작업을 만든다.
## 가설
planner·reviewer·builder·researcher·gardener 지침에 D0~D4 로드맵, UI 리뷰(스크린샷 직접 확인), 시뮬레이터 규칙 변경 시 Gate R 검사 추가, TP 명세 일치 확인을 넣으면, 2주 안에 큐가 새 로드맵 단계 이슈로 바뀌고 처리량은 유지된다.
## 변경
PROTOCOL 라벨(`area:tp` 추가, `area:typing` 은퇴), planner(단계 우선순위·UI 수용 기준·NEEDS_HUMAN 체험 피드백), reviewer(9~11항), builder(웹·규칙 변경), researcher(주제), gardener(은퇴 자산 정리). 루틴 주기·구성은 그대로다.
## 측정 지표와 측정창
머지 후 14일. (1) ready 큐 중 D1~D2 이슈 비율, (2) 일 평균 머지 수, (3) UI PR 중 reviewer가 스크린샷을 확인했다고 기록한 비율, (4) UI 관련 friction 건수.
## 성공 기준
(1) 7일 안에 100%, (2) 직전 주의 70% 이상(새 영역 학습 비용 감안), (3) 100%, (4) 같은 주제 3회 미만.
## 롤백 방법
역할 지침의 해당 문단을 되돌리는 PR. 로드맵·헌장 변경은 사용자 지시이므로 롤백 대상이 아니다.
