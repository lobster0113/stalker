## 판단: 6인 평가 성능이 C 단독보다 나빠졌는가
**나빠졌다는 근거는 없다.** 혼합 인원 run은 6인 딜을 C 단독의 약 절반(기대 11,200 대 20,000)만 봤는데도:
- LBR 현재 0.979 ± 0.356는 C 단독 네 시드(1.19–1.87)보다 낮고, 평균 전략 1.715 ± 0.388는 C 단독 범위(1.25–1.94) 안이다. 차이는 둘 다 표준오차 두 배 안쪽이다.
- 필드 8개 구성(self5 제외) 중 6개(tag5·lag5·nit5·station5·mixed_styles·mixed_regs)는 C 단독 시드 평균보다 낫다(lag5만 시드 범위 위로 +118, 나머지는 범위 안). maniac5는 평균보다 73 낮지만 시드 범위(−1,263 ~ −1,065) 안이다. **uniform5만 시드 범위 밖으로 낮다**(+711 대 최저 +878): 무작위 상대를 덜 착취한다. 이 구성은 전략 품질보다 착취 크기를 보므로 경보로 보지 않지만 기록해 둔다.
- 두 run 모두 미수렴이다(필드 −780 ~ −1,340 bb/100, #487 「필드」 절). 이 값들은 "망가지지 않았다"는 확인일 뿐 6인 품질의 순위가 아니다.

c1 key는 인원 수(`n<players>`)와 포지션 이름을 칸으로 가지므로 6인 정보 집합은 2–5인과 섞이지 않는다(ADR 0019 §3.2). 그래서 6인 성능이 2–5인 딜 때문에 나빠질 경로는 없고, 남는 차이는 6인 반복 수·시드·하드웨어다. 이번 결과는 그 예상과 맞는다. 6인 반복이 절반인데 LBR이 나쁘지 않은 이유는 확인하지 않았다(1시드, 표준오차가 차이만큼 크다).

**D 비용에 대한 신호(참고).** 6인 c1이 2×10⁴회에 380k 키라면, 혼합 인원은 5.6×10⁴회에 1.66M 키로 반복당 키가 1.56배다. 키가 반복의 0.35제곱 안팎으로 늘던 곡선(#487 X 절)을 6인 c1에 그대로 쓰면 5.6×10⁴회 6인 c1은 약 545k 키라 혼합 인원은 그 **약 3.0배**다(외삽, 참고). 2–5인 key가 새로 쌓인다는 ADR 0019의 예상(§3.2, §4 가정 D = C 비용의 0.5/1/2배)과 방향이 같다. 반복당 시간은 평균 인원 4인이라 6인보다 싸다(it/s 직접 비교는 하드웨어·워커 수가 달라 하지 않는다).

**메모리.** 16 워커 × 자식 최대 2.2GB + 부모 5.2GB ≈ 40GB로, #513 노트의 "약 30GB 안팎" 추정보다 크지만 64GB 안에 들어왔다. 체인을 이어 달리면 키가 계속 늘어 같은 구성에서 다시 넘칠 수 있다(대안 ② 색인 공유 메모리, `2026-10-e3-tp-keys.md` #513 절).

## 판단할 수 없는 것 (인원별 평가 없음, #384·referee-change)
- **2–5인 성능**: LBR·필드 평가기는 6인 고정이라 2–5인 정책의 LBR·필드는 재지 못했다. 2–5인 key가 "정상"인지(ADR 0019 §3.1 D가 보려던 것의 절반)는 인원별 평가기가 있어야 판단할 수 있다 — #384의 범위이며 평가기는 `referee/`라 referee-change 이슈가 필요하다.
- **인원별 실현 방문 수·키 수**: 요약 JSON의 `coverage`는 행동 이력 접두사별이라 인원별로 나뉘지 않는다. 키 문자열에 `n<players>`가 있으므로 결과 본문(체크포인트)에서 셀 수 있지만, 아티팩트를 이 환경에서 받지 못했다. 위 표의 인원별 비율은 설계상 기대값이다. → 후속: `pod_train` 결과/요약에 인원별 핸드 수와 키 수를 기록(에이전트 환경에서 대조 가능하게).
- **warm start 대 cold start**(ADR 0019 §3.2): 이번 run은 cold start 하나뿐이다.
- **6인 성능 차이의 크기**: 1시드 대 4시드, 반복·하드웨어가 달라 "나빠지지 않았다" 이상은 말할 수 없다.

### 해석
- **핸드 비율은 설계대로**: 인원별 핸드 7,970–8,048(기대 8,000, 표준편차 약 80)로 균등하다. 방문과 키는 인원이 적을수록 많다(2인 방문이 6인의 3.3배, 키는 1.7배). 반복당 키 비용은 2–3인이 높다.
- **표본이 가장 적은 인원**: 평가 핸드는 2–5인이 600(se 0.6–1.6), 6인이 1000. se가 가장 큰 쪽은 **2인**(LBR 5.46 ± 1.63)이다. 학습 쪽에서 방문·키가 가장 적은 인원은 **6인**(방문 61.5만, 키 17.1만)이다. 6인 키가 적은 것은 key에 포지션이 6개로 나뉘어 반복당 겹치는 키가 적은 쪽과 방향이 같다. 확인한 것은 아니다.
- **6인 값이 41515877838과 같은 범위인가**: 6인 LBR 현재 2.544 ± 0.410은 41515877838의 0.979 ± 0.356보다 높고 차이 1.57은 두 se 합성(0.54)의 약 2.9배라 **같은 범위로 볼 수 없다**. 평균 전략 1.421 ± 0.374 대 1.715 ± 0.388은 같은 범위다. 필드 6인 worst는 station5 −1,320.7 대 −1,313.7로 같다. 차이 후보는 반복 수(40k 대 56k), 시드 1개, 평가 딜이 아니라 학습 쪽 요인이다. 이 run의 6인 현재 LBR은 C 단독 시드 범위(1.19–1.87) 위로 벗어난다. 1시드라 원인은 확인하지 못했다.
- **인원별 LBR 추세**: 현재 LBR은 2인 5.5 → 6인 2.5로 인원이 적을수록 크다. 단 LBR 값은 인원이 다르면 같은 척도의 "품질"이 아니다(헤즈업은 팟당 변동이 크다). 인원 간 순위 비교는 하지 않는다.
- 필드 음수 bb/100은 인원이 늘수록 커진다(−264 → −1,321). 이것도 미수렴 정책이 상대를 착취하지 못하고 블라인드를 잃는 정도가 인원에 따라 달라서다. 합격선 없이 기록만 한다.
