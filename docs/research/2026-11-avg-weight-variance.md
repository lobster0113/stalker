# own-reach 평균 전략 가중치의 분산 제어 — 장난감 오라클 (#448)

- 배경: `avg_rule="own"`(#426)은 상대 도달 곱 Π로 나눠 불편이지만, E3 6인 CI에서 평균 전략 LBR의 시드 간 sd가 0.40(legacy 0.19)이다. 가중치 1/Π는 꼬리가 무겁다(중앙 22, 최대 7×10⁷, #426 측정).
- 수치는 모두 **로컬 참고값**(1코어, 판정 근거 아님). 재현: `python -m stalker.vcfr.avg_variance`(약 30초). 코드: `stalker/vcfr/avg_variance.py`, 테스트 `tests/test_avg_variance.py`.

## 1. 설정
- 게임: 3인 Kuhn(`toy.kuhn3`, 24딜). 헤즈업(Kuhn·Leduc)에는 나눌 상대가 없어 모든 추정기가 같으므로 돌리지 않았다. 이슈의 "3인 Leduc"는 리포에 없다 — 아래 §4 후속.
- 전략: 고정 σ에서는 증분이 모두 σ의 배수라 정규화한 정책이 가중치와 무관하게 σ가 된다(비교 불가). 그래서 **천천히 움직이는 σ_t**(skewed Dirichlet(0.3) 시작, 로짓 랜덤워크 0.15/단계)로 선형 평균(증분×t)을 비교한다.
- 진실: 같은 σ_t에서 `exact_update(avg_reach="own")`의 합. 지표: 키 질량 가중 L1(추정 정책, 진실 정책). bias = 30회 반복 평균 정책의 거리, err = 반복별 거리의 평균(bias ≤ err, 차이가 분산분).

## 2. 결과 (30회 반복)
| 추정기 | 100단계 bias / err | 400단계 bias / err |
|---|---|---|
| none (현재 own) | 0.0074 / 0.0304 | 0.0119 / 0.0332 |
| cap c=2 (1/Π를 2로 자름) | 0.0061 / 0.0231 | 0.0068 / 0.0168 |
| cap c=8 | 0.0081 / 0.0281 | 0.0080 / 0.0205 |
| cap c=32 | 0.0069 / 0.0286 | 0.0075 / 0.0230 |
| exact (20단계마다 정확 패스 ×20) | 0.0341 / 0.0341 | 0.0147 / 0.0147 |
| 키별 self-normalised | none과 동일(아래) | 동일 |

- **키별 self-normalise는 효과가 없다.** 행 Σwσ를 Σw로 나눈 뒤 액션에 걸쳐 정규화하는 것이므로, σ 행의 합이 1이라 서빙 정책은 none과 정확히 같다. 키 간 질량 비교가 필요한 곳이 없다.
- cap은 이 장난감에서 오차를 줄인다(400단계 err 0.033→0.017, c=2). 편향은 늘지 않았다(0.012→0.007). 가중치가 무한 분산인 꼬리를 자르는 이득이 편향 비용보다 컸다. 이론상 cap은 편향을 만들지만(큰 가중치의 기여를 버림) 여기서는 σ_t가 부드럽게 변해 정규화에서 상쇄된다.
- exact 패스는 샘플링 잡음이 0이지만 σ_t를 m단계마다 한 번만 보므로 σ가 움직이는 만큼 결정적 편향이 생긴다(100단계 0.034). 단계가 길어지면 줄어든다. E3에서는 정확 패스가 전체 트리 순회라 비용이 가장 크다.

## 3. 한계
- 장난감의 Π 꼬리는 E3(중앙 22, 최대 7×10⁷)보다 훨씬 얇다(3인 Kuhn은 깊이 3). cap 값 c의 최적은 E3에서 다를 수 있다. 장난감 결과는 방향(cap이 오차를 줄이고 편향을 키우지 않는다)만 말한다.
- 반복 30회·단일 시드(1)·단일 궤적이다. 큰 차이(2배)만 믿는다.

## 4. 추천과 후속
- **추천: cap, c≈2~8.** 구현이 한 줄(`min(1/Π, c)`)이고 상태가 없다. `E3Sampler(avg_cap=)`로 장난감에는 들어갔다(`avg_cap=None`이면 기존과 비트 동일, 테스트).
- E3 본체(`E3MCCFR`)에는 넣지 않았다. 옵션을 넣으면 체크포인트 버전·병렬 워커·`train_jobs`가 모두 영향을 받고 CI LBR 비교가 따로 필요하다. 후속 이슈 제안: ① `avg_cap` 옵션을 E3에 추가(체크포인트 버전 포함) ② 같은 시드 6인 mid에서 own vs own+cap(c=2,8)의 LBR 시드 간 sd 비교(CI) ③ 3인 Leduc 장난감 추가.
