# `opp.range` 모양 입력의 판별력과 입력 시간 (#159)

ADR 0011 검증표의 `opp.range` 모양·분포 행: 채택 기준 "점수 차 > 입력 오차, P50 ≤ 4초".
**모든 수치는 로컬 실행값(참고용)이다.** 재현: `python -m stalker.tp.range_shape_eval --n 200 --seed 159`
(약 6초). 코드 `stalker/tp/range_shape_eval.py`, 테스트 `tests/test_range_shape_eval.py`.

## 1. 측정 방법
- **스팟**: 리버 서브게임 600개(행동 원형마다 200). 보드 5장 무작위, 내 레인지 = 프리플랍 상위 30%,
  상대 프리플랍 레인지 = 상위 15/25/40% 중 하나. 상대 리버 레인지는 프리플랍 레인지를 보드 위
  강도(내 레인지 대비 에퀴티, `range_shape`와 같은 정의)의 레인지 내 분위로 거른다(가장자리는 로지스틱, 폭 0.04).
  - 폴라(벳 = 밸류 + 블러프): 상위 v(15–35%) + 하위 b(= v × 0.4–0.8)
  - 응축(체크콜): 분위 25–45% ~ 70–85% 사이 띠
  - 선형(밸류 벳·레이즈): 상위 q(30–60%)
- **정답**: 그 레인지의 5구간 분포와 `shape_of`가 내는 모양. 원형과 실제 모양은 대체로 같지만
  폴라 원형의 24%는 `merged`로 분류됐다(아래 표의 n이 원형별 200과 다른 이유).
- **비교하는 답**(모두 `range_shape.score`, 0–100)
  - `shape`: 정답 모양의 템플릿(중수, 한 번 탭)
  - `linear`: 선형 템플릿(같은 등급에서 "선형으로 착각")
  - `best_width`: 초보 너비 답 중 가장 점수가 높은 것(1% 격자) — 선형 착각의 **가장 관대한** 경우
  - 입력 오차: 정답 분포를 입력 장치로 넣을 때 잃는 점수. `quantized` = 5pp 칩 반올림(합 100 유지),
    `noisy` = 막대마다 N(0, 5pp) 잡음(비관적)

## 2. 결과 (seed 159, 정답 모양별)
| 정답 모양 | n | shape | linear | best_width | 차이: shape−linear | 차이: shape−best_width (P10) | 입력 오차 반올림 / 잡음 |
|---|---|---|---|---|---|---|---|
| 폴라 | 156 | 91.2 | 82.9 | 88.4 | **8.4** | 2.9 (−2.0) | 1.4 / 3.7 |
| 응축 | 201 | 91.8 | 73.9 | 79.4 | **17.9** | **12.5** (6.0) | 1.1 / 3.2 |
| 선형(대조군) | 174 | 90.5 | 90.5 | 92.1 | 0 | −1.6 (−4.0) | 1.0 / 3.5 |
| 혼합 | 69 | 88.9 | 83.5 | 89.4 | 5.4 | −0.5 (−6.2) | 1.3 / 3.4 |

스팟별로 "shape−best_width > 그 스팟의 잡음 입력 오차"인 비율: 응축 94%, 폴라 43%, 선형 0%.
시드 1·2에서도 같은 경향(폴라 shape−linear 9.6·9.4, shape−best_width 3.9·3.8; 응축 17.1·17.6, 11.9·12.4).

## 3. 해석
1. **채택 기준(점수 차 > 입력 오차)은 같은 등급의 착각(모양 템플릿 vs 선형 템플릿)에서 충족된다.**
   폴라 8.4, 응축 17.9 > 입력 오차(반올림 1.4, 잡음 3.7). 선형 스팟에서는 차이가 0이라 채점이
   모양을 가리지 않고 점수를 주지는 않는다.
2. **응축은 초보 너비 답과도 확실히 갈린다**(12.5, P10 6.0). 너비 답은 아무리 골라도 가운데가 볼록한 분포를 못 만든다.
3. **폴라는 초보 너비 답과 약하게 갈린다**(2.9: 반올림 오차보다 크지만 잡음 오차보다 작다, 스팟의 43%만).
   추정 원인(검증 안 함): 폴라 레인지는 넛급 질량이 크고, 타이트한 너비 답도 넛급에 질량을 싣는다. 너비 답이
   놓치는 것은 에어 구간 질량뿐이라 EMD 차이가 작다. 폴라를 템플릿 한 번 탭으로 답할 때의 점수 이득이 작다는 뜻이다.
4. 정답 분포를 직접 넣는 고수 답(`noisy` 96 안팎)은 어느 모양에서도 최적 너비 답보다 4–17점 높다.

**권고**(ADR 0011 후속에서 결정): 중수 모양 템플릿은 응축·선형에는 충분하다. 폴라에는 "블러프 비중" 막대 한 번
조정(에어 구간)을 기본 흐름에 넣거나, 폴라 피드백을 EMD 대신 에어 구간 질량 차이로 따로 주는 안을 비교한다.

## 4. 입력 시간 (추정, 실측 아님)
사람 세션 없이 P50을 잴 수 없다. 데모에는 결정당 입력 시간 기록(`stalker.itimes`, P50/P95)이 있지만
모양 입력 UI가 아직 없다. 아래는 키스트로크 수준 모델(KLM; Card·Moran·Newell의 근사값 M 정신 준비 1.35초,
P 가리키기 1.1초, 탭 0.2초)로 낸 **추정**이다.

| 등급 | 입력 | 추정 |
|---|---|---|
| 초보 | 너비 칩 1회: M + P + 탭 | 약 2.7초 |
| 중수 | 모양 카드 + 너비 칩: M + 2(P + 탭) | 약 4.0초 (판단을 두 번 하면 M 하나 추가 → 5.3초) |
| 중수 + 폴라 블러프 조정 | 위 + 막대 1회 조정: + M + P + 탭 | 약 6.6초 |
| 고수 | 모양 + 막대 2회 조정 | 약 9.3초 |

중수의 기본 흐름은 기준(P50 ≤ 4초) 경계에 있다. 너비를 모양 템플릿 기본값으로 미리 채워 탭 하나를 빼면 약 2.7초다.
**실측 P50은 데모 목업(모양 카드 + 너비 + 막대)에 `stalker.itimes` 기록을 붙이고 사람 체험으로 재야 한다** — 이
PR의 범위 밖이며, 후속 이슈로 분리한다.

## 5. 한계
- 스팟의 상대 레인지는 행동 원형으로 만든 것이지 균형 전략(MCCFR)의 실제 리버 레인지가 아니다. E2 정책의 리버
  레인지로 같은 측정을 반복하면 원형 가정을 뺄 수 있다.
- 턴은 측정하지 않았다(`strength_bins` 정확 계산이 리버의 약 44배 비용).
- ADR 0011이 든 E0 Leduc 환경은 카드 3장 랭크라 5구간 분포가 의미 있게 나오지 않아 쓰지 않았다.
