# 외부 설계 리뷰 반영 기록 (2026-10-30, #420)

- 원문: 소유자가 준 "STALKER / TP-GTO 심층 설계·기술 리뷰"(2026-10-30). 공개 문서(CHARTER·TP·GATES·ADR 0019·벡터 CFR 노트)와 프로젝트 개요를 읽고 쓴 독립 검토다. 코드·CI 원자료를 다시 돌리지 않았다고 스스로 밝힌다.
- 이 문서는 권고마다 **사실 확인 결과**와 **어디서 처리하는지**를 적는다. 수치의 근거는 CI뿐이다.

| 리뷰의 우려 | 확인 결과 | 근거 |
|---|---|---|

## 3. 받아들이지 않거나 보류한 것
- **실전 사이즈 메뉴 축소 방향의 절충**(§5.3의 "공통 근사"): 소유자 결정(ADR 0019 §1)은 실전 메뉴 전부다. 손실 기준을 만족하는 액션만 묶는 방안도 메뉴를 줄이는 쪽이라 하지 않는다. 계층형 정책은 무제약 기준과 EV를 비교하는 연구로만 남긴다.
- **하네스 규칙 변경**(PR 체크리스트, 서명 아티팩트, 평가·학습 권한 분리): harness 경로라 harness-change 이슈가 필요하다. 체크리스트 중 "실패 테스트 먼저"는 CLAUDE.md 코드 규칙에 이미 있다.
- **D·E 일정**: 바꾸지 않았다. R0는 B·S 구현과 병렬로 돌아 C 착수 시점만 R0 결과에 묶인다.
