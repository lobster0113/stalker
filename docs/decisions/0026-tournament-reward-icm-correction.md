# ADR 0026: 토너먼트 학습 보상 = ICM 에퀴티 + 단일 파라미터 보정(기본 0)과 CI 선택 절차

- 상태: 제안 → 이 PR 머지로 채택 (Builder 추천안으로 진행, `harness/PROTOCOL.md` §9)
- 이슈: #857 (#845 후속 A). #385(E 토너먼트)의 보상 형태를 정한다. 구현은 범위 밖(후속 절).
- 수치는 `docs/research/2026-11-icm-bias-measurement.md`(PR #856)의 **로컬 참고값**이다(CI 결과 아님). 원본: `docs/research/data/icm-bias-2026-11-13-{random,tag}.json`.

## 맥락
토너먼트 환경의 학습 보상은 칩 변화가 아니라 에퀴티 차이여야 한다(`docs/research/2026-11-icm-env-separation.md`). 순수 ICM(Harville)이 우리 시뮬레이터의 실제 상금 기대값과 얼마나 다른지 #845가 쟀다(프리셋 3 × 잔여 {2,3,4} × 스택 프로필 3 = 27칸, 에이전트 2종, 칸당 1000게임).

- **유의 칸(|z| ≥ 3 그리고 |diff|/pool ≥ 0.02)은 6칸, 전부 버블(잔여 = 상금권 + 1)**: 9max_sng_503020 remaining 4 skewed, 9max_sng_flat remaining 4 random·skewed, 각각 random·tag. 상금권 안(잔여 ≤ 상금 인원)은 표본 오차 범위다.
- **방향: ICM은 버블의 최단 스택을 과소평가한다.** 6칸 모두 가장 짧은 스택의 sim − ICM이 양수(예: 503020 skewed 스택 128 → ICM 26.1 대 실제 +39.2(random)/+54.3(tag), flat skewed 스택 457 → +30.9/+65.7 = pool의 최대 7.3%).
- **편향 크기는 에이전트에 따라 다르다**(같은 칸에서 tag > random). 고정 보정표는 정책이 바뀌면 틀린다.
- 한계: 칸당 스택 배치 1개, 레벨 0만, 다중 비교 보정 없음(측정 문서 「위험」).

## 선택지
**(a) 순수 ICM 에퀴티.** 단순, 파라미터 없음, 문헌의 표준. 단점: 버블에서 짧은 스택을 체계적으로 낮게 평가(pool의 2~7%) — #385가 가장 공들일 구간에서 틀린다.

**(b) ICM + 단일 파라미터 λ 보정(기본 0).** λ=0이면 (a)와 같아 퇴행 위험이 없고, λ는 학습 정책으로 CI에서 고른다. 단점: λ 선택 절차와 도구가 필요하고, 문헌의 FGS 정량 정의가 제각각이라 형태가 근사다.

**(c) 시뮬레이션 상금을 직접 보상.** 편향이 없다. 단점: 보상이 게임 끝에서야 나와 신용 할당이 어렵고 분산이 크며(핸드당 에퀴티 차이를 못 씀), 정책이 바뀔 때마다 롤아웃이 필요하다.

**(d) 고정 보정표(#845 값을 박음).** 구현이 쉽다. 단점: 편향이 정책의 함수라(tag > random) 학습된 정책이 바뀌면 순환·불일치 — 기각.

## 결정
**(b).** 보상은 보정 에퀴티의 차이, 평가는 계속 "ICM 에퀴티 + 페이아웃 시뮬 상금" **이중 기록**한다(시뮬 상금이 편향 순환을 끊는 기준).

### 수식
입력: 스택 벡터 `s`(칩 정수, 파산 0), 페이아웃 `p`(순위순, 상금 단위), 상금 인원 `K = len(p)`, 파라미터 `λ`. 살아 있는 선수 수 `m = #{s_i > 0}`.

```
S̄   = 살아 있는 선수의 평균 스택
g   = 1 if m == K + 1 (버블) else 0
s'_i = s_i + λ · g · S̄        (s_i > 0인 선수만; 파산자는 0 유지)
E_i(s; λ) = icm_equity(s', p)_i
```
- 출력: 선수별 상금 단위 **실수**(칩 정수 아님). 보상 = 한 행동 전후 `E_i`의 차이(포텐셜 차이라 합이 telescoping).
- 성질: ① **λ = 0이면 모든 s에서 `icm_equity(s, p)`와 같다**(테스트로 단언). ② 총합 보존: `Σ E_i = icm_equity(s', p)`의 합 = 남은 상금 합(가상 칩은 순위 확률만 바꾸고 상금 총량은 안 바꾼다). ③ 단조: 짧은 스택일수록 상대 증가율이 크다(가상 칩이 모두에게 같은 크기) → 측정된 방향(최단 스택 과소평가)과 일치.
- **허용 범위 λ ∈ [0, 1].** 1이면 버블에서 모두에게 평균 스택 하나를 더한 것(스택 비율이 가장 많이 평평해짐). 0 미만은 방향이 반대라 금지, 1 초과는 순위 구조를 뒤집을 수 있어 금지(구현이 범위 밖이면 `ValueError`).
- 근거: `2026-11-icm-env-separation.md`의 FGS(남은 게임에서 짧은 스택도 수익성이 있다)와 리스크 프리미엄 하한을 "가상 스택 가산 한 파라미터"로 단순화했다. 버블에서만 켜는 이유는 #845에서 편향이 버블에만 유의했기 때문이다(상금권 안에서 λ>0은 오차를 새로 만든다). 한계: 형태는 근사이며 문헌에 정량 정의가 없다 — 그래서 CI 선택(아래)이 효과를 검증한다.

### CI 선택 절차
1. **후보 격자** `λ ∈ {0, 0.05, 0.1, 0.2, 0.35, 0.5}`(0 포함 필수 — 비교 기준).
2. **측정 조건**: 학습 정책(모든 좌석 동일 정책) 대칭 필드, `icm_grid` 격자의 버블 칸(프리셋 × remaining = K+1 × 프로필 3종, 칸당 스택 배치 ≥ 3개 시드, 게임 ≥ 1000)에 **상금권 안 칸을 함께** 넣는다.
3. **지표**: 칸별 `|sim_prize_mean − E_i(s; λ)|`의 생존자 최대값 ÷ 상금 풀(= `|diff|/pool`)과 z. 요약 두 값: (i) 버블 칸 중 `|z| ≥ 3 and |diff|/pool ≥ 0.02` 칸 수, (ii) 버블 칸 `|diff|/pool` 평균.
4. **채택 규칙**: 상금권 안 칸의 유의 칸 수가 λ=0보다 늘지 않는 λ만 후보로 두고, 그중 (i)이 최소인 λ, 동률이면 (ii)가 작은 쪽, 그래도 동률이면 **λ가 작은 쪽**. 어떤 λ도 (i)을 λ=0보다 줄이지 못하면 λ=0(순수 ICM)을 채택한다.
5. **재선택 시점**: 토너먼트 정책이 교체될 때(새 체크포인트를 `web/app/policy`에 올리기 전)와 페이아웃 프리셋 집합이 바뀔 때. 선택한 λ와 지표 표는 결과 JSON에 기록한다.
6. 평가 쪽(Gate·학습 로그)은 보정 에퀴티와 시뮬 상금을 둘 다 기록한다. 심판 연결(`referee/`)은 `referee-change` 이슈에서 따로 한다.

## 결과 (영향받는 코드 경로)
- 새 보상 모듈(후속 1): `stalker/core/icm.py` 위에 `bubble_corrected_equity(stacks, payouts, lam)` 형태. 기존 `icm_equity`·`icm_equity_mc`는 변하지 않는다.
- `stalker/tools/icm_calibration.py`·`icm_grid.py`: λ 옵션 추가(후속 2). 출력 스키마가 바뀌면 `schema_version`을 올린다.
- #385의 학습 보상이 이 모듈을 쓴다. 이 ADR은 코드·심판 경로를 바꾸지 않는다.
- 위험: 측정이 ICM을 모르는 에이전트(random·TAG)로 한 값이라, ICM을 아는 정책끼리는 편향이 작아 λ=0이 채택될 수 있다 — 설계상 허용된 결과다. 로컬 수치이므로 판단은 CI 선택 절차의 결과로 한다.
