# ADR 0006: 게임 내 기억은 AI-1(계층 베이지안 수축 통계)을 기본으로, AI-2(통계+GRU)는 Gate C 제거 실험으로 정당화한다

- **2026-10-27 ADR 0008: 참고 자료로 유지** (TP `opp.*` 추정에 재사용 가능).
- 상태: **초안** (2026-10-24, 이슈 #9). Reviewer가 판정한다. 번호: 0004·0005가 이미 사용 중이라 이슈 본문의 "0004 초안"을 0006으로 올렸다.
- 근거: `docs/research/2026-10-24-game-memory.md`, ADR 0003, `referee/GATES.md`(Gate C·L).

## 맥락
ADR 0003은 게임 내 기억을 요구하나 통계 형식·사전·시퀀스 인코딩·평가 표본 수를 정하지 않았다.

## 선택지
| | 설명 | 장점 | 단점 |
|---|---|---|---|
| A | AI-1만: 컨텍스트별 베이지안 수축 통계 | 해석 가능, 가벼움, 과반응 방지가 구조에 내장 | 순서·추세 정보 없음 |
| B | AI-2만: GRU가 원관측을 직접 학습 | 표현력 | 데이터 적은 환경에서 불안정, 해석 어려움, 기록·유형화에 불리 |
| C | AI-1 + AI-2(통계를 GRU 입력에도 포함) | 통계가 기본, GRU는 잔차 정보 | 구현·학습 비용 큼 |

## 결정 (추천)
1. 통계 입력은 Dirichlet-다항 사후 평균 + 기회 수 + 사후 분산을 함께 낸다. 사전은 모집단(포지션·스택·버블 컨텍스트별) 기반으로 시작하고 계층 사전은 변형으로 실험한다.
2. 컨텍스트는 계층 수축: 레벨 0/1은 항상, 레벨 2는 기회 수 충분 시 마스크 해제. 컨텍스트 정의는 한 모듈에서만 정하고 `DATA_SUFFICIENCY.md` 셀과 정렬한다.
3. AI-2 = AI-1 입력 + 최근 K 시퀀스(좌석 슬롯 기반, player_id 암기 금지) → GRU. 은닉은 game_id 경계에서 영(0), 핸드 경계에서 유지.
4. AI-0/1/2는 메모리 입력 마스킹으로 가중치를 공유해 학습하고(같은 시점 확률 동시 기록), 주기적으로 별도 모델로 교차검증한다.
5. Gate C: 주 가설 1개 사전 지정, 대응(duplicate) 설계, 검정력 0.9, 최소 의미 효과 2%p(군당 약 4.4만 판 ρ=0.5 기준, 연구 문서 §7.2, ρ=0.5 대응). 안전성은 적대적 풀 손실로 별도 보고.
6. 표본 수 공식의 정의를 한 곳(`referee/` 쪽)으로 통일한다(리뷰 §2.5와의 차이 해소).

## 결과
후속 구현 이슈 F1~F4 (연구 문서 §7·§9, PR 본문 "후속"). 보호 경로(`referee/`)를 건드리는 항목은 `referee-change` 이슈로 분리한다.
