# ADR 0005: 고속 엔진 1단계는 PokerKit 규칙의 순수 파이썬 복제(`FastHand`), Rust는 측정 근거가 생길 때

- 상태: 채택 (2026-10-24, #19). ADR 0004의 "첫 투자는 Rust 고속 엔진" 추정을 **단계화**한다.
- 범위: 핸드 엔진(딜·베팅·정산). ICM·에퀴티 가속은 범위 밖.

## 맥락
- RL 학습(#21)과 게이트 평가(군당 1.5만~2.2만 토너먼트)는 수억 핸드를 요구한다. PokerKit `Hand`는 9인 무작위 플레이 약 80~140핸드/초/코어(로컬)로, 비용 산정(ADR 0004)의 병목이다.
- PokerKit은 규칙 정답(ADR 0002)으로 유지한다. 어떤 엔진이든 PokerKit과의 차등 테스트(Gate R)를 통과해야 한다.
- CI는 `ubuntu-latest` + Python 3.12, `pip install -e .`뿐이다. 빌드 툴체인 추가는 `.github/`(하네스 경로) 변경을 요구한다.

| A. 순수 파이썬 복제(`FastHand`) | **실측 약 4,400** (PokerKit 대비 약 55배, 6인 약 37배; 로컬 참고값) | 의존성 0, 빌드·CI 변경 없음, `Hand`와 같은 인터페이스(드롭인), 1회 실행 안에 완성·검증 | 파이썬 인터프리터 한계 — 10⁵/초는 불가 |

## 결정
1. **지금은 A를 채택한다.** `stalker/tournament/fast_hand.py::FastHand`가 PokerKit 0.7.7 토너먼트 모드의 규칙(앤티는 최하위 팟의 데드 머니, 블라인드 상한, 실효 스택 0인 플레이어 제외, 숏 올인 재오픈 규칙, 미콜 반환, 쇼다운 핸드 킬 후 팟 재구성·병합, 홀수 칩은 버튼 왼쪽 첫 승자)과 덱 소비 순서까지 복제한다.
2. 차등 하네스 `stalker/tools/diff_engine.py`는 엔진 비의존적이다. 이후 어떤 엔진(B·C·D)도 같은 하네스로 10만 핸드 일치를 보여야 채택한다.
3. **Rust(C)로 가는 조건**: RL 롤아웃(#21)을 프로파일링해 엔진 시간이 전체의 30%를 넘을 때. ADR 0004의 추정대로 신경망 포함 처리량이 50~150핸드/초/스레드라면, 4,000핸드/초 엔진의 몫은 5% 미만이므로 지금 Rust에 투자할 이유가 없다.

## 결과
- PokerKit 대비 ≥20배 목표는 A로 충족(슬로 테스트 `test_throughput_at_least_20x_pokerkit`가 CI에서 비율로 확인 — 기계 속도에 덜 민감).
- `python -m stalker.tools.bench_engine`이 처리량, `python -m stalker.tools.diff_engine --hands 100000`이 규칙 일치를 재현한다.
- 디렉터(`run_game`)는 아직 PokerKit `Hand`를 쓴다. 엔진 선택 옵션은 후속(인터페이스가 같아 교체 비용이 작다).
- PHH 내보내기(`to_phh`)는 `FastHand`에 없다. 기록이 필요하면 같은 시드·액션을 `Hand`에 재생한다.
