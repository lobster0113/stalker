# ADR 0003: 핵심 AI는 게임-경계 인식 재귀 정책(RL)이며, ICMizer 상회가 최소 성공 기준이다

- 상태: 채택 (2026-10-24). ADR 0002를 **부분 대체**한다(아래 "ADR 0002와의 관계").
- 근거: 사용자 연구보고서 `docs/research/2026-10-24-user-rnd-report.pdf`, 검토 `docs/research/2026-10-24-rnd-report-review.md`.

## 결정
1. **핵심 정책**: 좌석 토큰(≤9, 마스킹) 인코더 + 카드·팟 수치 인코더 + 게임 내 상대 메모리(집계 통계 + 최근 K 공개 액션 + GRU) → Actor(합법 액션 마스킹, 이산 레이즈 크기) / Critic(최종 상금 기대값). 최적화는 Recurrent PPO/IMPALA 계열 후보. 구조는 출발점이며 제거 실험(AI-0/1/2)으로 단순화될 수 있다.
2. **기억 경계**: 메모리 키는 `game_id`. `START_GAME`에서 생성, `END_GAME`에서 폐기, `NEW_HAND`에서는 핸드 입력만 재설정. 학습 시 trajectory를 game_id로 자르고 hidden state를 각 게임 첫 스텝에서 초기화.
3. **관측 계약**: 현재 테이블 + 현 게임 누적 공개 관측 + 공개 토너먼트 요약(블라인드·앤티·레벨·생존자·지급 순위·상금 벡터·평균 스택·**스택 분포 고정 길이 요약**). 타 테이블 개별 로그·비공개 카드·난수 시드는 입력 금지. 관측은 단일 Observation Builder만 생성하고 누출 테스트의 대상이 된다.
4. **보상**: 최종 상금 − 참가비. 학습 시 지급 구조별 정규화, 평가 시 실제 단위·ROI 보고.
5. **성공 판정**: `referee/GATES.md`의 Gate A/B/C와 레벨 0~3. ICMizer 비교는 자체 구현한 ICMizer-등가 참조기(심판 자산)로 수행하고, 실물 ICMizer 대조 세트는 선택적 보강.
6. **기록**: 결정마다 AI-0(기억 끔)과 AI-1/2(기억 켬) 정책 확률을 함께 기록(학습 트랙의 핵심 재료), policy_version·logprob 포함.
7. **연산 자원**: P0~P2는 현 인프라(루틴 VM, Actions). P3 착수 전 학습 자원 ADR을 작성하고, 비용·하드웨어 결정은 `ops:NEEDS_HUMAN.md`로 사용자에게 요청한다.

## ADR 0002와의 관계
- 유지: PokerKit 엔진 채택, 상용 도구 비의존, 출력에 가정(트리·에퀴티 모델·버전) 기록.
- 변경: "오라클(솔버 라이브러리) + 적응 계층"이 핵심 AI라는 결정을 대체한다. 솔버·내시 계산기는 (a) Gate A 참조기, (b) Gate B 참조 봇, (c) RL 부트스트랩 교사, (d) 이론 앵커로 쓴다.
- "사전계산 라이브러리 + 조회" 처리량 전략은 참조 봇·교사 데이터 생성에 그대로 쓴다.
