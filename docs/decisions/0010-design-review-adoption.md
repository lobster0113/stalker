# ADR 0010: 설계 리뷰(2026-10-27) 반영 — 정답의 의미·정보 계약·판정 언어·단계 게이트

- 상태: 채택 (2026-10-27, 대화 세션). 사용자가 리뷰 문서를 주고 "판단해서 반영하라"고 위임했다.
- 근거: `docs/research/2026-10-27-design-review.md`(이하 "리뷰"). 이 ADR은 리뷰의 각 제안을 **채택 / 수정 채택 / 보류**로 판정하고, 고친 문서를 적는다.
- 영향: `docs/TP.md`(v0.1), `referee/GATES.md`, `docs/CHARTER.md`, `docs/plans/2026-10-27-development-plan.md`(v1.1), ADR 0009(보완).

## 요약
리뷰의 핵심 지적, 즉 "가장 어려운 부분(정답의 의미, 공개 정보 경계, 강도 판정 논리, 브라우저가 줄 수 있는 정답의 범위)을 이미 해결된 것처럼 썼다"는 지적이 옳다. 대규모 학습 전에 **정답 계약**을 먼저 고정하고, 작은 환경(E1)에서 TP 제한의 대가를 숫자로 증명한 뒤 확장한다. 데모(D1)는 별도 트랙으로 계속한다.

| P0-01 GTO와 "잘 이기는 AI" 구분 | 채택 | 균형 근사의 **보증**은 정확한 BR을 계산할 수 있는 환경(E1, 소형 장난감 게임)에서만 쓴다. LBR·학습된 공격자 결과는 "**발견된 착취 이득(하한)**"으로만 보고한다. Gate Q를 Q1~Q4로 나눈다. 제품 이름 "TP-GTO"는 유지하되, 모델 카드·보고서에 인증 수준을 적는다 |

## 하지 않는 것
- TP를 지금 v1로 확정하지 않는다. v0.1은 리뷰의 구조(층·필드·N/A)를 반영한 **중간본**이며, v1은 E1·장난감 게임 실험과 판별력 측정 뒤에 확정한다.
- 수치 기준(허용 오차·δ·τ)을 지금 확정하지 않는다. 판별력 측정 뒤 referee-change로 정한다.
