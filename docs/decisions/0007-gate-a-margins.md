# ADR 0007: Gate A 기준선 허용치와 δ를 스팟 가치 규모에 맞춘다

- 상태: **초안** (2026-10-26, 이슈 #73). Reviewer가 판정한다.
- 근거: `referee/GATES.md` Gate A, `referee/anchors/icm_reference.py`, 아래 측정(로컬 실행, 참고용 — 판정 근거는 CI).

## 맥락
#73은 Gate A 판정 경로를 GATES.md 초기값 δ_ni = 상금풀 0.1%, δ_min = 0.2%(스팟당 기대상금)로 구현하고, "항상 폴드" 후보가 ①(내시 상대 비열등)에서 실패함을 검증 기준으로 요구한다. 구현해 보니 두 가지가 맞지 않았다.

1. **기준선 잡음.** 참조기 기본 허용치 `BASELINE_TOL = 1e-3`(좌석별 최선응답 이득 ≤ 상금풀 0.1%)에서 hero의 잔여 이득이 0.03~0.10%로 δ_ni와 같은 크기다. 그 결과 항상 폴드가 "내시 기준선"보다 EV가 높게 나오는 스팟이 16개 중 9개였다.
2. **δ가 스팟 가치보다 크다.** 기준선을 1e-5로 수렴시켜도, 항상 폴드의 손실은 스팟당 상금풀의 0.008%(9인 버블 UTG 12bb)~0.25%(6인 비버블 SB 8bb)다. 스팟 EV는 169 클래스 전체 평균이고 대부분의 핸드는 원래 폴드라, 한 스팟의 결정 가치 자체가 작다. 형식별 평균 손실: 6인 버블 0.044%, 9인 버블 0.012%, 6인 비버블 0.15%, 9인 비버블 0.09%. δ_ni = 0.1%이면 항상 폴드가 버블 두 형식에서 비열등 통과한다 → 게이트가 아무것도 걸러내지 못한다.

| 스팟(1e-5) | 항상 폴드 손실 | 내시 잔여 |
|---|---|---|
| 6b 4개 | 0.043 / 0.064 / 0.033 / 0.037% | ≤ 0.001% |
| 6n 4개 | 0.100 / 0.249 / 0.090 / 0.147% | ≤ 0.001% |
| 9b 4개 | 0.022 / 0.008 / 0.009 / 0.010% | ≤ 0.001% |
| 9n 4개 | 0.038 / 0.160 / 0.064 / 0.110% | ≤ 0.001% |

## 선택지
| | 설명 | 장점 | 단점 |
|---|---|---|---|
| A | δ 유지, 이슈 기준 미충족으로 보고 | 문서 변경 없음 | 항상 폴드가 통과하는 게이트 — 판정 신뢰성 0 |
| B | 지표를 "결정 핸드 조건부 EV"로 바꿈 | 핸드 희석 제거 | 정의·구현 변경이 크고 ICMizer 비교 단위와 어긋남 |
| C | 지표 유지, δ를 측정된 스팟 가치에 맞춰 낮추고 기준선 허용치를 δ보다 충분히 작게 | 변경 최소, 판정 전(사전 등록 단계) 조정 | 9인 버블처럼 결정 가치가 작은 형식은 여전히 여유가 작음 |

## 결정 (추천: C)
- Gate A 명세(`referee/gate_a/spec_v1.json`)에 `baseline_tol = 1e-5`, `baseline_max_iter = 20000`을 고정한다(수렴 실패 시 판정 중단). 기본 `BASELINE_TOL`은 다른 사용처를 위해 그대로 둔다.
- δ_ni = 5e-05(0.005%), δ_min = 1e-4(0.01%). 비율 δ_min = 2·δ_ni는 GATES.md 최초안과 같다. δ_ni는 가장 작은 형식 평균 폴드 손실(0.012%)보다 충분히 작고 기준선 잔여(≤0.001%)의 5배 이상이다.
- 아직 어떤 후보도 판정받지 않았으므로 사전 등록 원칙(표본 정책)을 어기지 않는다. 이후 변경은 referee-change.

## 결과
- 연산: 1e-5 수렴은 16스팟 기준 한 프로세스에서 약 5~6분(9인 스팟당 ~28초). 같은 프로세스의 후보들은 해를 공유(캐시)한다. 전체 v1 검증은 slow 테스트.
- 후속 제안: 9인 버블 스팟의 결정 가치가 작아 판별력이 낮다 → 스팟 세트 v2에서 결정 가치(항상 폴드 손실)가 δ_ni의 4배 이상인 스팟만 고르는 기준을 검토.
